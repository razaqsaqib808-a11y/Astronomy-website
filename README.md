# 🌌 Astronomy Website

A modern and interactive astronomy website built using HTML, CSS, and JavaScript.  
It explores space, planets, stars, and galaxies with a clean and responsive design.

---

## 🚀 About The Project

This project is designed to provide an engaging experience about the universe.  
It includes multiple pages and space-themed visuals to make learning about astronomy fun and interactive.
